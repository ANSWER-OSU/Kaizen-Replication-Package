## Artifact Replication Repository for the study on Kaizen: Metamorphic Fuzzing and Differential Testing for LLM-Translated HPC Applications

This repository contains the data and code to replicate the results of the paper "Kaizen: Metamorphic Fuzzing and Differential Testing for LLM-Translated HPC Applications", Oscar Ludwig, Ninad Anklesaria, Zheming Jin, Swaroop Pophale, Kausar Moshood, Christian J. DeVore, Brandon Gill, Cassius Villareal, Keita Teranishi, and Manish Motwani.

The repository contains the pre-computed results and experiment logs for easy reference.


For replicating the entire experiment, see SETUP.md. Please make an issue report if the setup instruction are missing anything.
